# Use Case Diagram — هوم‌استور

## ۱. مقدمه

این دیاگرام نشان می‌دهد چه کسی (Actor) با سیستم چه کاری (Use Case) انجام می‌دهد.

## ۲. Actors

| Actor | نقش |
|-------|------|
| مشتری | خریدار محصولات |
| ادمین | مدیریت محصولات و سفارش‌ها |
| انباردار | مدیریت موجودی |

## ۳. Use Cases

### ۳.۱ مشتری
- مشاهدهٔ محصولات
- جست‌وجو و فیلتر
- مشاهدهٔ جزئیات محصول
- مقایسهٔ محصولات
- افزودن به سبد خرید
- ثبت سفارش
- پیگیری سفارش

### ۳.۲ ادمین
- ورود به پنل
- افزودن محصول
- ویرایش محصول
- حذف محصول
- مشاهدهٔ سفارش‌ها
- تغییر وضعیت سفارش

### ۳.۳ انباردار
- مشاهدهٔ موجودی
- به‌روزرسانی موجودی
- مشاهدهٔ هشدار کمبود

## ۴. سناریوی اصلی — خرید

1. مشتری وارد صفحهٔ محصولات می‌شود
2. محصولات را جست‌وجو/فیلتر می‌کند
3. محصول را به سبد اضافه می‌کند
4. به صفحهٔ سبد می‌رود
5. ثبت سفارش می‌کند
6. شمارهٔ پیگیری دریافت می‌کند
