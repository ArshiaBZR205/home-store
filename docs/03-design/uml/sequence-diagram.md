# Sequence Diagram — هوم‌استور

## ۱. مقدمه

این دیاگرام ترتیب تعاملات بین اجزا را در یک سناریو نشان می‌دهد.

## ۲. سناریو: ثبت سفارش

### ۲.۱ Actors
- **مشتری** — کاربر
- **Frontend** — React
- **Backend** — Express
- **Database** — PostgreSQL

### ۲.۲ ترتیب

1. مشتری روی «ثبت سفارش» کلیک می‌کند
2. Frontend درخواست POST به `/api/orders` می‌فرستد
3. Backend درخواست را اعتبارسنجی می‌کند
4. Backend موجودی را در Database چک می‌کند
5. Backend سفارش را ثبت می‌کند
6. Backend موجودی را کاهش می‌دهد
7. Backend شماره پیگیری برمی‌گرداند
8. Frontend پیام موفقیت نشان می‌دهد

## ۳. سناریو: مشاهدهٔ محصولات

1. مشتری وارد صفحهٔ محصولات می‌شود
2. Frontend درخواست GET به `/api/products` می‌فرستد
3. Backend لیست را از Database می‌خواند
4. Backend لیست را برمی‌گرداند
5. Frontend نمایش می‌دهد

## ۴. خطاهای ممکن

| خطا | کد | راهکار |
|------|-----|---------|
| موجودی کافی نیست | 400 | پیام خطا |
| سفارش تکراری | 409 | پیام خطا |
| خطای سرور | 500 | Retry |
